## Resumen ejecutivo

Goss Specialty Coffee opera como cafetería aliada dentro del Hotel El Peñón. Este paquete busca **integrar la experiencia de café de especialidad con la operación hotelera**, generando valor mutuo:

- Para el **hotel**: un servicio de alimentos y bebidas de calidad, amenities de café de marca, mejor imagen del espacio común y mayor visibilidad digital.
- Para la **cafetería**: mayor rotación, posicionamiento del punto de venta y una relación comercial estable y escalable a los demás hoteles del grupo Bit Hotels.

Las cinco propuestas son **complementarias e independientes**: el hotel puede aprobar una, varias o todas.

## Cómo continuar

1. Revisión de cada propuesta por parte de la administración del hotel.
2. Ajuste de cantidades, alcance y condiciones según necesidad operativa.
3. Firma de acuerdo(s) y definición del cronograma de arranque.

> Documento de trabajo. Cada propuesta es un modelo base **mejorable y ajustable** en conjunto con el hotel.
