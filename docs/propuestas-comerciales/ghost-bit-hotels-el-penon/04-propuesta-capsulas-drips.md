# Propuesta 04 — Cápsulas y drips para habitaciones

**Ghost Specialty Coffee → Bit Hotels El Peñón**  
**Referencia:** GSC-BH-EP-04-CAPSULAS-DRIPS  
**Fecha:** 17 de agosto de 2026

---

## 1. Objetivo

Dotar las habitaciones de Bit Hotels El Peñón de una experiencia de **café de especialidad in-room**, con producto etiquetado con la marca del hotel, listo para máquinas espresso de cápsula y para preparación tipo drip / pour-over.

Esto refuerza el posicionamiento lifestyle del hotel y extiende la calidad de Ghost Specialty Coffee más allá de la barra.

## 2. Productos y precios (tarifa hotel)

| Producto | Descripción | Costo para el hotel (COP) |
|----------|-------------|---------------------------|
| **Cápsula** | Café de especialidad para máquina espresso de cápsulas | **$1.700** c/u |
| **Drip** | Café de especialidad para preparación drip / filtro en habitación | **$2.000** c/u |

Precios de alianza. IVA según régimen aplicable.

## 3. Especificaciones

### 3.1 Cápsulas

- Café de especialidad Ghost  
- **Etiqueta con marca del hotel** (Bit Hotels El Peñón / Bit Hotels)  
- Perfiles disponibles (propuesta):  
  - Espresso clásico (chocolate / caramelo)  
  - Espresso intenso  
  - Espresso suave / nota frutal  
- Compatibilidad: confirmar modelo de máquina en habitación (Nespresso-compatible u otra) en visita técnica

### 3.2 Drips

- Porción individual para preparación drip  
- Etiqueta hotel + origen / notas de cata resumidas  
- Ideal para huéspedes que prefieren filtrado  
- Presentación lista para amenity kit o minibar

### 3.3 Branding

Incluye diseño de etiqueta con:

- Logo / nombre del hotel  
- Mención “Specialty Coffee” / Ghost Specialty Coffee (según acuerdo de cobranding)  
- Lote / frescura / instrucciones breves de preparación

## 4. Modelo de suministro sugerido

| Modalidad | Descripción |
|-----------|-------------|
| Stock inicial | Kit por habitación (ej. 2 cápsulas + 1 drip) × N habitaciones |
| Reposición | Pedido semanal o al alcanzar mínimo de inventario |
| Cortesía vs cobro | Definir: amenity incluido en tarifa, o cargo a habitación / minibar |

### Ejemplo de pedido inicial (referencia 28 habitaciones)

| Ítem | Cantidad | Subtotal COP |
|------|----------|--------------|
| Cápsulas ($1.700) | 56 (2 × 28) | $95.200 |
| Drips ($2.000) | 28 (1 × 28) | $56.000 |
| **Total stock inicial estimado** | | **$151.200** |

*Sin incluir diseño de etiqueta (puede absorberse en el primer pedido de alianza o cotizarse aparte si hay varias variantes).*

## 5. Beneficios

- Experiencia premium en habitación sin cocina compleja  
- Diferenciación frente a café genérico de amenity  
- Continuidad de marca entre barra Ghost y habitación  
- Posible upsell (packs adicionales en recepción / minibar)
