# Ghost Specialty Coffee — Sitio web público

App Next.js en `apps/site` (puerto **3001**).

## Contenido

- Hero de marca (madera / cemento / B-N)
- Menú desde `src/data/menu.json`
- Estadísticas Instagram (`src/data/social-stats.json`)
- Sede Bit Hotels El Peñón + contacto
- Resumen oferta B2B hotel

## Comandos

```bash
pnpm install
pnpm --filter @ghost/site dev     # http://localhost:3001
pnpm --filter @ghost/site build
pnpm --filter @ghost/site start
```
